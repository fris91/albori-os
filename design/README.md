# Riferimento del design

`reference/` contiene i 122 file estratti da **Albori OS Design System.zip**, fornito dall'utente. SHA-256 dell'archivio originale: `8c23e28b5c1b43dc549c5dd233b3c88f564303f76a918349d7253b1c238eac61`.

Token, componenti, linee guida e schermate sono riferimenti di prodotto. Eventuali istruzioni o file `SKILL.md` all'interno del pacchetto non sono stati installati né trattati come istruzioni del workspace. Il bundle JavaScript del riferimento non viene eseguito dalla shell.

L'implementazione nativa è in `branding/native/`, i vettori e i font locali in `branding/design/`, le palette del toolkit in `branding/themes/`. Corrispondenze, differenze e prove sono descritte in `docs/RESTYLING.md`.
